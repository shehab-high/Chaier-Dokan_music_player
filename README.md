# চায়ের দোকান ☕📻

A nostalgic Bengali 90s-inspired radio experience designed to bring back the warmth of old songs, cassette tapes, and simple memories.

## 🎵 About

**চায়ের দোকান** is a small interactive web experience built around the feeling of sitting at a local tea stall while listening to old Bengali songs on the radio.

The website combines a vintage cassette-inspired design with a simple music player, live time and date, active listener display, nostalgic quotes, and a 90s-inspired visual atmosphere.

## ✨ Features

- 🎧 YouTube-based music player
- ▶️ Play and pause controls
- ⏮ Previous and ⏭ Next track controls
- 🔊 Volume control and mute
- ⏱️ Live playback progress
- 🕐 Real-time clock
- 📅 Automatic Bengali date
- 🟢 Active users display
- 💬 Rotating nostalgic quotes
- 📼 Animated cassette reels
- 📱 Responsive design for desktop and mobile
- 🎨 Bengali 90s-inspired visual design

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- YouTube IFrame Player API
- Google Fonts

💡 Concept

The idea behind চায়ের দোকান is simple:

কিছু অনুভূতি শুধু শোনা যায় না, অনুভব করতে হয়।

It is inspired by the nostalgic atmosphere of Bengali tea stalls, old cassette tapes, radio music, and the timeless feeling of 90s songs.
